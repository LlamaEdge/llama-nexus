# Simple Task Skill

This is a minimal skill for handling simple tasks.

## When to Use

Use this skill when:
- The task is straightforward
- No external tools are needed
- A simple response is sufficient

## Guidelines

1. Understand the task
2. Provide a clear, concise response
3. Keep the output well-formatted
